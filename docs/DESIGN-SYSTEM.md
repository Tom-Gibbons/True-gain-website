# True Gain Website Design System

## Design tokens

The coded design tokens live in:

`styles/design-tokens.css`

They define:

- Brand colours
- Type sizes
- Spacing
- Layout widths
- Border radii
- Motion timing
- Shadows

## Spacing

Use an 8px-based spacing system:

- 8px
- 16px
- 24px
- 32px
- 48px
- 64px
- 96px
- 120px

## Typography

### Headings

- Uppercase
- Bold
- Tight line height
- Strong visual hierarchy

### Body text

- Clean sans-serif
- Comfortable line height
- Short paragraphs
- Generous whitespace

## Buttons

### Primary

- Gold background
- Black text
- Uppercase label
- Subtle lift on hover

### Secondary

- Transparent background
- Gold border
- Ivory text

### Glass

- Transparent dark background
- Blur effect
- Used over hero imagery

## Cards

Cards should use:

- Charcoal background
- Thin low-contrast border
- Generous internal spacing
- Gold accents
- Subtle hover movement
- One clear call-to-action

## Image rules

- Use wide cinematic crops
- Keep subjects slightly off-centre
- Leave negative space for live HTML copy
- Avoid busy commercial gym scenes
- Avoid group training imagery
- Prioritise one-to-one coaching cues

## Responsive behaviour

### Desktop

- Multi-column layouts
- Large hero typography
- Full navigation

### Tablet

- Reduced gaps
- Two-column grids where practical
- Collapsed navigation

### Mobile

- Single-column layouts
- Stacked buttons
- Reduced section padding
- Large touch targets
- No essential content hidden

## Motion

Use motion sparingly:

- 180–250ms hover effects
- 450ms image or section transitions
- Small vertical entrance animations
- No distracting looping animation

## Reusable components

- `components/Button.tsx`
- `components/SectionHeading.tsx`
- `components/ServiceCard.tsx`
- `components/MembershipCard.tsx`

These components should be used when new pages are added so the visual system stays consistent.
