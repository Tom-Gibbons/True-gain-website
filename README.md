# True Gain Performance v2

Vercel-ready Next.js website.

## Deploy without GitHub
1. Download and unzip the project.
2. Sign in to Vercel.
3. Create a new project.
4. Upload/import the project folder.
5. Vercel should detect Next.js automatically.
6. Click Deploy.

Before launch, replace temporary images, confirm pricing, connect the contact form, and add legal pages.
