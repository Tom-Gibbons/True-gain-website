# True Gain Performance v3

Premium Next.js website for True Gain Performance.

## GitHub update instructions

Replace the following files in your existing repository:

- `app/page.tsx`
- `app/globals.css`
- `app/layout.tsx`
- `package.json`

Place the logo at:

- `public/true-gain-logo.png`

Vercel will deploy automatically after the GitHub commit.

## Before public launch

- Replace all temporary Unsplash images with approved True Gain photography.
- Replace placeholder testimonials.
- Connect the consultation form.
- Add privacy, cookie and terms pages.
- Confirm prices and membership inclusions.
