## Uploading to GitHub

Upload the contents of this folder to the root of your GitHub repository.

GitHub should show these folders on the first page:

- `app`
- `components`
- `docs`
- `public`
- `styles`

It should also show:

- `package.json`
- `tsconfig.json`
- `next-env.d.ts`

Vercel will redeploy automatically after the GitHub commit.
